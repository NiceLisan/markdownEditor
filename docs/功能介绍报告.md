# Doocs/MD 微信 Markdown 编辑器 - 功能介绍报告

## 一、产品概述

**产品名称**：Doocs/MD  
**版本**：2.1.0  
**产品定位**：一款高度简洁的微信 Markdown 编辑器，将 Markdown 文档自动即时渲染为微信公众号兼容的图文格式。

**核心价值**：解决微信公众号文章排版繁琐的痛点，让创作者专注于内容写作，而非格式调整。

**访问地址**：

- 在线使用：https://md.doocs.org
- 开源地址：https://github.com/doocs/md

## 三、核心功能模块

### 3.1 Markdown 渲染引擎

核心渲染引擎（@md/core）负责将 Markdown 转换为微信公众号兼容的 HTML，具备以下能力：

#### 3.1.1 标准 Markdown 支持

完整支持 CommonMark 和 GFM（GitHub Flavored Markdown）规范：

- **标题**：支持 1-6 级标题，提供 5 种样式（默认、主题色、下边框、左边框、自定义）
- **段落与文本**：粗体、斜体、删除线、下划线
- **列表**：有序列表、无序列表、任务列表
- **链接与图片**：自动识别并处理
- **表格**：标准 Markdown 表格渲染
- **代码块**：支持 60+ 种语言的语法高亮，Mac 风格代码块装饰（红绿灯图标）
- **引用块**：多层嵌套引用支持
- **分割线**：水平分割线

#### 3.1.2 扩展语法

| 扩展功能         | 语法示例                                     | 说明                                                       |
| ---------------- | -------------------------------------------- | ---------------------------------------------------------- |
| **GFM 警告块**   | `> [!NOTE]` / `> [!TIP]` / `> [!WARNING]` 等 | 5 种类型的提示框（note、tip、warning、important、caution） |
| **数学公式**     | `$E=mc^2$`、`$$\sum_{i=1}^{n}$$`             | 行内公式与块级公式，支持 KaTeX 渲染                        |
| **Mermaid 图表** | `mermaid ... `                               | 流程图、时序图、甘特图、饼图等                             |
| **PlantUML**     | `plantuml ... `                              | UML 类图、用例图、活动图等                                 |
| **AntV 信息图**  | `infographic ... `                           | 数据可视化信息图                                           |
| **Ruby 注音**    | `[文字]{注音}`                               | 中文拼音/注音标注                                          |
| **脚注**         | `[^1]` + `[^1]: 内容`                        | 学术引用风格的脚注系统                                     |
| **目录生成**     | `[TOC]`                                      | 自动生成文章目录                                           |
| **Front Matter** | `---\ntitle: xxx\n---`                       | YAML 元数据支持                                            |
| **滑动组件**     | 自定义语法                                   | 滑动展示内容                                               |
| **滑块容器**     | 自定义语法                                   | 可滚动内容区域                                             |

#### 3.1.3 主题系统

内置 4 套精心设计的主题：

| --------------------------- | -------------------------- | ---------------- |

| **grace（优雅）**           | 柔和的配色，优雅的排版     | 文艺、生活类内容 |

| **topwar_game（口袋奇兵）** | 游戏风格主题               | 游戏类公众号     |

## 五、数据模型

### 5.1 文章（Post）

```typescript
interface Post {
  id: string; // 唯一标识（UUID）
  title: string; // 文章标题
  content: string; // Markdown 内容
  history: {
    // 历史记录
    datetime: string; // 记录时间
    content: string; // 历史内容
  }[];
  createDatetime: Date; // 创建时间
  updateDatetime: Date; // 更新时间
  parentId?: string | null; // 父级 ID（支持层级结构）
  collapsed?: boolean; // 折叠状态
}
```

### 5.2 模板（Template）

```typescript
interface Template {
  id: string; // 唯一标识（UUID）
  name: string; // 模板名称
  content: string; // Markdown 内容
  description?: string; // 模板描述
  tags?: string[]; // 标签
  createdAt: number; // 创建时间戳
  updatedAt: number; // 更新时间戳
}
```

### 5.3 文件系统节点（FileSystemNode）

```typescript
interface FileSystemNode {
  name: string; // 名称
  path: string; // 路径
  type: "file" | "directory"; // 类型
  children?: FileSystemNode[]; // 子节点
  handle?: FileSystemFileHandle | FileSystemDirectoryHandle;
}
```

### 5.4 快捷指令（QuickCommand）

```typescript
interface QuickCommandPersisted {
  id: string; // 唯一标识
  label: string; // 显示名称
  template: string; // 指令模板（{{sel}} 占位选中文本）
}
```

## 八、总结

Doocs/MD 是一款功能全面、高度可定制的微信 Markdown 编辑器，核心优势包括：

1. **一站式解决方案**：从 Markdown 编辑到微信排版，全流程覆盖
2. **强大的渲染引擎**：支持标准 Markdown + 多种扩展语法
3. **丰富的图床选择**：13 种图床支持，满足各种存储需求
4. **AI 深度集成**：14+ 服务商、100+ 模型，文本创作与图片生成
5. **灵活的自定义**：主题、CSS、字体、颜色均可定制
6. **多端部署**：Web、CLI、Docker、VS Code、uTools 多端可用
7. **开源免费**：ISC 许可证，代码完全开源

该产品有效解决了微信公众号排版的痛点，让创作者能够专注于内容本身，而非格式调整。
