## 什么是 doocs/md？

doocs/md 是一款开源的微信 Markdown 编辑器，核心理念很简单：

**你只管写内容，排版交给它。**

在左侧用 Markdown 语法写作，右侧实时预览渲染效果，一键复制即可粘贴到微信公众号编辑器，完美适配微信的排版规范。

但原版虽然好用，却还缺少一些我们日常运营中刚需的功能。于是，我们决定自己动手——**对 doocs/md 进行了一系列深度魔改。**

## 魔改升级了哪些功能？

### 01 一键同步发布到 30+ 平台

这是本次魔改最重磅的功能。

基于 COSE（文章同步助手）浏览器扩展，我们实现了**一次编辑，多平台同步发布**。

目前支持的平台包括：

**媒体平台（12 个）**
微信公众号、今日头条、知乎、百家号、网易号、搜狐号、微博、B 站、少数派、Twitter、抖音、小红书

**博客平台（9 个）**
CSDN、博客园、掘金、Medium、51CTO、SegmentFault、开源中国、InfoQ、简书

**云平台及开发者社区（9 个）**
腾讯云、阿里云、华为云、华为开发者联盟、百度千帆、支付宝开放平台、魔搭社区、火山引擎、电子发烧友

操作流程非常简单：

1. 写完文章后，点击顶部「发布」按钮
2. 勾选需要同步的平台
3. 自动提取标题、封面图、描述
4. 一键发布，实时查看各平台状态

**渐进式登录检测**：每个平台检测登录状态后立即更新 UI，不用等所有平台都检测完。

从此告别一个个平台登录、复制、粘贴、排版的重复劳动。

### 03 口袋奇兵专属主题 + 游戏专用语法

如果你运营的是游戏类公众号，这个主题一定会让你眼前一亮。

**口袋奇兵主题**是专门为游戏公众号定制的主题，包含游戏风格的配色和排版。

更厉害的是，我们还新增了一套**游戏专用的 Markdown 扩展语法**，用 `:::` 包裹即可使用：

```markdown
:::topwar-intro
游戏文章引言/介绍区块
:::

:::video
视频号嵌入（支持昵称、描述、视频 URL）
:::

:::topwar-data
数据透视区块（支持自定义标题）
:::

:::topwar-buff
增益/Buff 效果展示区块
:::

:::topwar-bubble
聊天气泡区块（支持自定义头像）
:::

:::topwar-tip
提示/技巧区块（支持自定义图标）
:::

:::topwar-head
文章头部封面区块
:::

:::topwar-review
评测/展示区块（支持 2 或 4 宫格图片布局）
:::

:::topwar-end
文章结尾区块
:::

```

这些组件渲染后都是微信公众号兼容的 HTML 格式，直接复制粘贴即可使用，无需任何额外操作。

### 06 多文章管理 + 历史记录

原版只能编辑一篇文章，魔改后支持：

- **多文章侧边栏管理**：文章列表快速切换
- **父子层级结构**：支持文件夹/文章多层级组织
- **历史记录**：每 30 秒自动保存，最多保留 10 条历史版本，随时回溯
- **拖拽排序**：文章顺序随意调整
- **多种排序模式**：A-Z、Z-A、按创建/编辑时间排序

---

### 07 本地文件夹实时同步

基于 File System Access API，实现了：

- 选择本地文件夹后，编辑器内容与本地文件实时同步
- 防抖同步（1 秒延迟），避免频繁写入
- 切换文件时自动同步旧文件

对于习惯用本地文件管理的创作者来说，这个功能非常实用。

---

### 08 CLI 本地部署升级

如果你更喜欢在本地运行，CLI 也进行了全面升级：

- **集成浏览器自动启动**：启动服务后自动打开浏览器（支持 Windows/macOS/Linux）
- **Windows 可执行文件**：支持打包为独立的 .exe 文件，无需安装 Node.js
- **Express 5 服务器**：现代化服务端框架
- **本地文件上传服务**：支持本地图片上传
- **端口自动回退**：指定端口被占用时自动切换可用端口

使用方式：

```bash
npm i -g @doocs/md-cli
md-cli
```

或者直接下载 Windows 可执行文件，双击即可运行。

## 如何使用？

**方式一：在线使用（推荐）**

直接访问：https://md.doocs.org

无需安装，打开浏览器就能用。

**方式二：CLI 本地运行**

```bash
npm i -g @doocs/md-cli
md-cli
```

**方式三：Docker 部署**

```bash
docker run -d -p 8080:80 doocs/md:latest
```

**方式四：VS Code 扩展**

在 VS Code 插件市场搜索 "doocs-md" 安装。
